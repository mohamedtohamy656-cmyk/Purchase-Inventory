# 📦 Purchase & Inventory Power BI Dashboard

## 📊 Overview

Power BI dashboard for analyzing procurement and inventory performance,
including purchase orders, vendors, categories, locations, and trends.

## 🚀 Dashboard Preview

!![Project-Purchase-Inventory](https://github.com/mohamedtohamy656-cmyk/Purchase-Inventory/blob/main/PBIDesktop_oOYlePl4Uv.gif)
## 📌 Key KPIs

- Total PO Amount
- Total Purchase Orders
- Pending PO Count
- Pending PO Percentage
- Invoiced Purchase Orders

## 📈 Dashboard Pages

- Overview Dashboard
- Procurement Trend
- Purchase Tree
- Price Trend
- Category Trend
- Purchased Item Details
- Pareto Analysis
- Drill Through Analysis

## 🛠 Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel / Data Modeling

## 🎯 Project Goal

To provide procurement insights by tracking spending,
vendor performance, purchasing trends, and inventory locations.
